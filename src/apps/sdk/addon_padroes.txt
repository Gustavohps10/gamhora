# Guia de Implementação: Arquitetura de Menus no SDK e Refatoração de Addon de Testes

Este documento orienta a implementação da arquitetura de menus extensíveis dentro do `@metric-org/sdk` e a adequação do plugin de testes em `src/tests/redmine-for-tests/src/index.ts`.

---

## 1. Diretrizes Arquiteturais

1. **Separação UI vs Execução:** Menus expõem apenas metadados declarativos serializáveis (`id`, `label`, `icon`, `type`, etc.). Callbacks e lógicas de execução pertencem aos comandos em Node.js ou barramentos de eventos.
2. **Reuso de Registry Genérico:** Evitar criar classes e interfaces de registry duplicadas; padronizar com `IRegistry<T>`.
3. **Ponto de Entrada Único do Addon:** O arquivo principal do plugin exporta uma classe que implementa `IAddon`, recebendo `AddonContext` no método `activate()`.

---

## 3. Adaptação do Plugin de Testes (`redmine-for-tests`)

**Localização:** `src/tests/redmine-for-tests/src/index.ts`

O plugin deve ser refatorado para implementar `IAddon`, registrando o conector de `DataSource`, os itens da `Sidebar` e as ações/popover da `Timerbar`:

```ts
import { AddonContext, IAddon } from '@metric-org/sdk'
import { RedmineDataSource } from './RedmineDataSource'

export default class Redmine4TestAddon implements IAddon {
  private dataSource = new RedmineDataSource()

  activate(context: AddonContext): void {
    // 1. Registra capacidade de DataSource
    context.dataSources.register(this.dataSource)

    // 2. Registra Menus na Sidebar (Itens e Subitens de navegação)
    context.menus.sidebar.register({
      id: 'redmine-sidebar',
      label: 'Redmine',
      icon: 'Layers',
      children: [
        {
          id: 'redmine-issues',
          label: 'Minhas Tarefas',
          href: '/addons/redmine/issues',
          icon: 'ListTodo',
        },
        {
          id: 'redmine-projects',
          label: 'Projetos',
          href: '/addons/redmine/projects',
          icon: 'FolderGit2',
        },
      ],
    })

    // 3. Registra Ação Rápida e Popover na Timerbar
    context.menus.timerbar.register({
      id: 'redmine-sync-action',
      type: 'action',
      label: 'Sincronizar',
      icon: 'RefreshCw',
      tooltip: 'Sincronizar apontamentos com Redmine',
    })

    context.menus.timerbar.register({
      id: 'redmine-timerbar-popover',
      type: 'popover',
      icon: 'Layers',
      tooltip: 'Opções do Redmine',
      items: [
        {
          id: 'redmine:open-current-issue',
          label: 'Abrir Tarefa no Navegador',
          icon: 'ExternalLink',
          shortcut: 'Ctrl+Shift+O',
        },
        {
          id: 'redmine:force-full-sync',
          label: 'Forçar Carga Completa',
          icon: 'DownloadCloud',
        },
      ],
    })

    // 4. Registra os handlers dos comandos declarados
    context.commands.register('redmine:open-current-issue', async () => {
      // Lógica de comando executada no Node.js
    })

    context.commands.register('redmine:force-full-sync', async () => {
      // Disparo de rotinas ou eventos de sincronização
    })
  }

  deactivate(): void {
    // Limpeza de conexões ou listeners
  }
}
```

---

## 4. Critérios de Validação

1. **Tipagem Estrita:** `src/apps/sdk` deve compilar com TypeScript sem emissão de `any` implícito.
2. **Isolamento de Contratos:** Os arquivos em `src/apps/sdk/src/contracts/menus/` não devem conter dependências de Electron (`ipcRenderer`, `BrowserWindow`) nem de React (`JSX`, `ReactNode`).
