# Calendars (Agendas e Reuniões)

Addons do tipo **Calendars** conectam o Metric a agendas corporativas para exibir compromissos do dia e permitir a conversão direta de reuniões em apontamentos de tempo.

## Estrutura de um Calendar Addon

Um plugin de calendário permite que o usuário veja sua grade de reuniões no painel diário e converta compromissos concluídos em logs de tempo com 1 clique.

```typescript
import type { IAddon, AddonContext } from '@metric-org/sdk'

export interface ICalendarEvent {
  id: string
  title: string
  startTime: string
  endTime: string
  description?: string
}

export default class GoogleCalendarAddon implements IAddon {
  public id = 'google-calendar'
  public name = 'Google Calendar'
  public version = '1.0.0'

  public async fetchTodayEvents(context: AddonContext): Promise<ICalendarEvent[]> {
    // Consulta a API do Google Calendar via OAuth token salvo no storage
    const token = await context.storage.get('accessToken')
    const response = await fetch('https://www.googleapis.com/calendar/v3/calendars/primary/events', {
      headers: { Authorization: `Bearer ${token}` },
    })
    const data = await response.json()

    return data.items.map((event: any) => ({
      id: event.id,
      title: event.summary,
      startTime: event.start.dateTime,
      endTime: event.end.dateTime,
    }))
  }
}
```
