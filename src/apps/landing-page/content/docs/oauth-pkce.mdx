# Autenticação OAuth 2.0 PKCE

O Metric fornece uma API nativa de **OAuth 2.0 com PKCE (Proof Key for Code Exchange)** via `context.oauth`. Esse fluxo elimina a necessidade de incluir `CLIENT_SECRET` nos addons e dispensa a abertura de servidores HTTP locais.

## O Fluxo em 5 Passos

1. **Geração de Desafio PKCE**: O addon chama `context.oauth.generatePKCE()` para obter `codeVerifier` e `codeChallenge`.
2. **Navegador**: O addon monta a URL do provedor (Discord, Google, Microsoft, etc.) e dispara `context.oauth.authorize({ authUrl, state })`.
3. **Redirecionamento**: O provedor redireciona para a Landing Page em `https://metricapp.com.br/oauth/callback?code=...&state=...`.
4. **Deep Link (`metric-app://`)**: A Landing Page executa o protocolo `metric-app://oauth/callback`, que entrega os parâmetros de volta ao aplicativo Desktop.
5. **Troca do Token**: O addon recebe o `code` e faz o POST diretamente ao endpoint de token do provedor enviando o `code_verifier` (sem secret).

## Exemplo de Implementação

```typescript
public async handleLogin(context: AddonContext): Promise<void> {
  // 1. Gera par PKCE
  const { codeVerifier, codeChallenge } = context.oauth.generatePKCE()
  const state = `plugin_${Date.now()}_${Math.random().toString(36).substring(2, 7)}`

  const CLIENT_ID = 'SUA_CLIENT_ID_PUBLICA'
  const REDIRECT_URI = 'https://metricapp.com.br/oauth/callback'

  const authUrl =
    `https://discord.com/api/oauth2/authorize?client_id=${CLIENT_ID}` +
    `&redirect_uri=${encodeURIComponent(REDIRECT_URI)}` +
    `&response_type=code&scope=identify` +
    `&code_challenge=${codeChallenge}&code_challenge_method=S256&state=${state}`

  // 2. Aguarda a resolução via Deep Link do sistema operacional
  const result = await context.oauth.authorize({
    authUrl,
    state,
    timeoutMs: 120000,
  })

  if (!result.code) {
    throw new Error('Autorização cancelada ou código não recebido.')
  }

  // 3. Troca o código pelo access_token usando PKCE
  const params = new URLSearchParams({
    client_id: CLIENT_ID,
    grant_type: 'authorization_code',
    code: result.code,
    code_verifier: codeVerifier,
    redirect_uri: REDIRECT_URI,
  })

  const response = await fetch('https://discord.com/api/oauth2/token', {
    method: 'POST',
    headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
    body: params,
  })

  const { access_token } = await response.json()

  // 4. Salva o token com segurança no storage do workspace
  await context.storage.set('accessToken', access_token)
}
```
